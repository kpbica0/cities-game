# Игра в города — Россия

Браузерная игра «Гoroda»: ты против бота. Города только РФ.

## Играть онлайн

После выкладки на GitHub:

**https://kpbica0.github.io/cities-game/**

Инструкция: `GITHUB-PAGES.md`  
Открой ссылку на телефоне — VPN не нужен.

## Локально

Дважды кликни `index.html` или открой папку в браузере.

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | Страница игры |
| `js/game.js` | Логика и бот |
| `js/cities.js` | 1100+ городов РФ |
| `russia-cities.json` | Источник списка (arbaev/russia-cities) |
| `build_cities.py` | Пересборка `cities.js` из JSON |

Подробнее: `КАК-ИГРАТЬ.md`
